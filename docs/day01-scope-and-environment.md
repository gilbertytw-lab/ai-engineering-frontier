# Day 1：專案範圍與環境基線

日期：2026-08-27

## 今天要解決的問題

只用過網頁對話式 AI 的讀者，常常不知道本地 AI 專案應該從哪裡開始，也容易一開始就安裝太多框架。Day 1 先固定目標、非目標與環境基線，讓後續每一天都能回答「今天新增了什麼能力」。

## 目標讀者

- 使用過 ChatGPT、Claude 或 Gemini 等網頁對話式 AI。
- 想在自己的電腦嘗試本地 LLM、文件問答或知識庫。
- 不預設已經了解 Transformer、向量資料庫、Agent framework 或模型訓練。

## 30 天後的最小成果

讀者可以將自己的 Markdown／文字文件放入指定位置，建立可重建索引，提出問題後取得附來源回答；若資料不足，系統會明確表示沒有足夠證據。系統另外提供至少一個唯讀的知識操作，並受到 context、步數、路徑與錯誤處理限制。

## 範圍邊界

### 必須完成

- 本地 LLM 的基本呼叫介面。
- 可重複執行的聊天流程。
- 原始文件、整理頁與衍生索引的責任分界。
- 至少一條 lexical 或 embedding retrieval 路徑。
- 固定 context budget 的證據組裝。
- 附來源回答與 no-answer 行為。
- 唯讀工具、輸入驗證、步數上限與基本評估。

### 不列入核心完賽條件

- 模型微調或自行訓練。
- 多 Agent 協作。
- 開放式 shell 或自動修改使用者檔案。
- 需要雲端服務才能執行的部署。
- 大型向量資料庫維運、複雜 GraphRAG 或進階推論加速。

## Python 版本策略

目前 `python3` 顯示的 3.9.6 只是這台電腦的系統直譯器，不代表專案要鎖在 3.9。Python 3.9 已於 2025-10-31 結束官方支援，因此不適合作為 30 天專案的基線。

本專案從 Day 2 起以 Python 3.13.x 建立隔離環境；3.12 列為保守相容版本，3.14 列為後續測試版本。實際採用的模型 runtime 和套件仍要在安裝後做 smoke test，不能只看套件宣告的最低 Python 版本。
